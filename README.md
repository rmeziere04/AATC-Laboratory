# AATC-Laboratory
The unofficial code notebook for Purdue University's Acoustics and Audio Technology Club.

Hello BoilerMakers!

Here are the rules:

1. Please keep your stuff in your directory (folder). The exceptions to this rule are group directories (e.g. "Tutorials") which are open to all.
2. Upload stuff which is relevant to the projects we pursue.
3. Do not upload code that cannot compile.
4. Make sure to ask someone first before editing their stuff.
5. Label your commits appropriately.
6. If you need a new directory in main (AATC-Laboratory), please ask the maintainer first.
7. To qualify as a tutorial, your code must be both functional and well explained with comments.
8. Slop (unedited, poorly understood AI code) is banned. (who do you think we are, CS Majors?)

Remember: This is not a scratchpad. If you've ever done formal research before, think of this as a laboratory notebook. Everything here should be reproducible one someone else's machine.

Do Code, Have Fun!
